# PIT II — Cupcakes Gourmet | Vagner William Matos Alves Lima

Projeto acadêmico de **Vagner William Matos Alves Lima — RGM 33902739**, desenvolvido como continuidade da PIT I.

## Contexto
Na PIT I foi escolhida a **Situação-Problema 2**, relacionada à elaboração dos principais artefatos UML para um aplicativo mobile de uma loja virtual de cupcakes.

O projeto trabalhou:
- diagrama de caso de uso;
- casos de uso expandidos;
- diagrama de classes;
- diagrama de sequência;
- identificação de atores;
- levantamento das funcionalidades do sistema.

## Objetivo
Dar continuidade à modelagem desenvolvida na PIT I e transformar os requisitos e artefatos UML em uma solução funcional, documentada e testável.

## Elementos definidos na PIT I
- Cliente;
- Administrador;
- Serviço de entrega;
- Produto;
- Carrinho;
- Pedido;
- Pagamento;
- Entrega.

## PIT II
Nesta etapa, a proposta é implementar uma aplicação web responsiva que represente o fluxo principal de compra de cupcakes, mantendo a documentação e o código-fonte em um repositório GitHub.
